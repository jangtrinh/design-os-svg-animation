## Phase 3 — skill `skills/es-tutorial-video/` (tool-product profile)
- `SKILL.md` (≤120 lines, frontmatter `name: es-tutorial-video`, description "Use when …" ≤200 chars): procedure Concept → Build → Check → Hand over → Adjust, the two owner gates, a "What goes wrong" table.
- `rules.md` (numbered; Statement / Keep it / Rejected when): includes at least verbatim evidence only, no home path on screen or in committed media metadata, music licence file never committed, chapter clip ≤ window − 0.8 s, bar grid measured not guessed, captions never overlap, owner gates, `display=''` not `block`, 3-digit beat names, metadata stamps off in Blender renders.
- `concepts.md`: how to turn a build folder into chapters (input → contract → passes/revision ladder → gates → fit → presentation → delivery → honest limits → lessons → outro).
- `look.md`: numbered eye-checks (captions readable, no clipping at the stage edge, card fan on stage, portrait slots, seam frames) + "Without a browser" clause.
- `contract.json`: GENERATED by `scripts/build-tutorial-contract.mjs` from the kit's CLI/config surface (config keys, element types and their fields, CLI flags), first line/field sha256; `--check` exits 1 when stale.
- `build.mjs`: `scaffold <build-dir> <slug>` creates `promo/<slug>-tutorial/` from a template (config, empty timeline skeleton, extract-evidence skeleton, gitignore); `render <project> [--aspect] [--beats|--full --shards N]` drives the kit (shards in parallel + join).
- `validate.mjs`: named checks, one line per failure `<check>: <what to fix>`, exit 0/1/2, `--help`. Checks: config schema; every asset/evidence key referenced by the timeline exists; every script segment has a clip and fits its chapter (reuse mix `--check` logic); no `/Users/` in evidence, assets (`strings`), staged media; music source + bed + mixes are gitignored; beat frame names 3-digit.
- `look.mjs`: renders the fixed shot list from look.md (beat sheet + seam frames) into one sheet PNG, prints machine items, exit 1 on any machine item.
- `examples/`: `ck-001` and `dc-01` pointers (paths to the migrated projects) — both must pass build(beats) + validate + look.
- `ATTRIBUTION.md`: Pixabay Content License (The_Mountain "Technology"), Free To Use (Alegend "Dawn"), ElevenLabs (voice), Antigravity image-generator (DC-01 regenerated sheets).
