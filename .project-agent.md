# design-os-svg-animation — project agent card

- product: Design OS SVG Animation Engine (Motion IR, Studio Player, promo recreations)
- stack: Node 22 ESM (`.mjs`), TypeScript (strict), Python 3 gates, puppeteer-core
- localhost_port: 4323
- dev server: `npm run dev` → `http://127.0.0.1:4323` (strict port, loopback only)
- port source of truth in code: `scripts/local-server-config.mjs`

## Binding rules
- Never start a server on another port; export/audit/capture scripts import the port from `scripts/local-server-config.mjs`.
- Gates before done: `npx tsc --noEmit`, `npm test`, `python3 scripts/anti-flop-gate.py`.
- Icons: Phosphor only (`@phosphor-icons/react` in React components); SVGL for brand marks; zero emojis in UI.
