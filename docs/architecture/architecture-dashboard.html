2. Anti-Flop Invariants & Hardrules

01

Camera vs Cursor Decoupled Motion Rule

Strictly ban concurrent camera panning/zooming and cursor movement. Motion is sequenced: Move Camera → Settle → Move Pointer → Click.

02

3-Second Hook & Frame 1 Contract

Frame 1 (frameIndex 0) must display hero UI + high-contrast text caption. 85% of mobile viewers are muted; no slow black fade-ins allowed.

03

2–4s Pattern Interrupt Rhythm

Every 2.0 to 4.0 seconds, fire an editorial pattern interrupt (1.12x spring zoom punch, camera pan, callout pop) to prevent mid-roll viewer drop-off.

04

Screenshot Beats Screen Recording (2x DPR)

Retina 2x device pixel ratio captures ensure pristine 2x focus zoom without compression artifacts, cursor drift, or framerate jitter.

Multi-Aspect Safe Zones

Adaptive master composition avoids UI clipping and platform overlay overlap (TikTok/Reels UI buttons, search bar, and captions).
